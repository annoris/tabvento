# Tabvento Local Execution

Tabvento runs missions using a local browser and your directly configured AI model provider. It does not require a cloud browser subscription or external hosted account.

See the [Tabvento Guide](docs/tabvento.md) to configure direct providers or local Ollama, and to unlock Live Browser Mode via Solana (`3HvUMCUSSHEdtA35UuD4J7mbgpTxJ7LgT2X7GfdzvBdm`, minimum `$88 USD`, no maximum limit).
